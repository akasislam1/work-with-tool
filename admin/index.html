Connect to GitHub

This panel saves your changes straight to your GitHub repository. Vercel then updates the live site automatically. Nothing is sent anywhere else.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new
  2. Under Repository access, choose Only select repositories and pick this site's repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token, copy it and paste it above.

The token is the key to this panel. Anyone without it can open this page but cannot change anything. Never share it.
